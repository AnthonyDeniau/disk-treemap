# Changelog

## 0.1.0

- Python CLI with no runtime dependencies and a prebuilt offline HTML viewer.
- Recursive, lazy-loaded canvas treemap with click details and keyboard-accessible folder contents.
- Allocated/logical sizes, exclusions, hard-link accounting and symlink metadata.
- Iterative traversal, partial scans and cleanup on cancellation/output failure.
- Cross-platform CLI CI, layout tests, offline browser tests and synthetic examples.
